# 0.2.3

Explained refusals.

- When a plain-language request is not run, the clarification now ends with a deterministic
  reason: what the model interpreted (action, state, county, city, status, limit) and which
  grounding rule refused it, or that the model answer could not be read, with a sanitized,
  bounded excerpt of that answer. Reasons never include provider records or exception text.
- No manifest, grant or protocol changes.
