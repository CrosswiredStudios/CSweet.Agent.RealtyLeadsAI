# 0.2.4

State-level requests no longer depend on the model.

- `QuickBrief`: a chat message that names exactly one US state, asks for leads or research, and
  carries no other filter, place name, ID, negation or acknowledgement is interpreted
  deterministically as `state=XX` (optional "N leads", 1–10). The planner is not called, so the
  answer cannot vary with the model, the platform's surrounding instructions or recalled memory.
- Word-like abbreviations (IN, OR, ME, OK, …) count as states only when written in capitals;
  "West Virginia" is not also "Virginia".
- Planner prompt rewritten for small models: a state alone is enough geography, worked examples,
  the contract repeated in the user turn, and an explicit note that role, planning and memory
  instructions do not apply to this step. Grounding and limits are unchanged.
- No manifest, grant or protocol changes.
