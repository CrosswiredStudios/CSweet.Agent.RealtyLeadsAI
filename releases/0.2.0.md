# 0.2.0

Lead Research Analyst. Moves to SDK 5.8.0 and plugin 0.2.0 (publisher-neutral remote MCP).

- Accepts manager delegations written as `research-brief.v1` lines, deterministically: valid
  briefs are accepted, invalid ones clarified with the exact defect, credential-shaped ones declined.
- On execution runs exactly one search, de-duplicates by lead ID, publishes a
  `realtyleads.lead-brief.v1` artifact with all eleven reviewed fields and the criteria used, and
  closes the delegation when its own brief marker appears in the recorded execution evidence.
- Chat keeps the 0.1.0 behavior (bounded model intent, grounding, escaped output) and also saves
  a brief when artifact creation is granted; replies show at most ten rows.
- Code split into brief grammar, planner, research service, renderer and publisher.
- New grants: `platform.artifact.create.v1`, delegation and tracking capabilities, and
  subscriptions to delegation received/tracking changed events.
