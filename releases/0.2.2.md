# 0.2.2

Planner parsing for reasoning models, found during installed acceptance with a local vLLM model.

- Reasoning models quote the JSON schema template and drafts in their thinking before the real
  answer. The planner now considers every balanced JSON object in the model text, latest first,
  and uses the last one that is a valid intent (`Search`, `Lookup` or `Clarify`). A stray
  unclosed brace earlier in the text cannot hide the answer.
- The planner output budget rises from 800 to 2000 tokens so reasoning cannot truncate the
  final answer; the answer itself remains under 100 tokens and each candidate object is still
  capped at 4 KB.
- No manifest, grant or protocol changes.
